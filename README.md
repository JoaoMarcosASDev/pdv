# PDV

Este é um projeto para portfólio Full-Stack focado no Back-End.

Um PDV (Ponto de Venda), é um software que oferece uma interface para auxiliar na finalização de uma, ou mais, venda(s), realizando calculos de faturamento, gerênciamento de estoque, geração de metricas de dados, notas fiscais etc. (Um exemplo comum no dia a dia é o caixa de um supermercado).

Consequêntimente reduz gastos, e facilita nas tomadas de decisões.

> [!Note]
> [Clique aqui para ver o planejamento e as especificações do projeto](./planejamento-md/planejamento.md)

### O que é necessário
* Armazenamento de Banco de Dados local com possibilidade de migrar para a nuvem:
    Armazenamento:
    * Local: SQLite 3
    * Em Nuvem: PostgreSQL
* Interface visual web (Front-end):
    Tecnologias:
    * HTML
    * CSS (Possivelmente substituir por algum framework de estilização)
    * JavaScript
* Intermediário da interface visual e banco de dados (Back-end):
    Tecnologia :
    * Node.Js

> [!NOTE]
> Este projeto visa desenvolver uma base sólida, então serão evitado o uso de bibliotecas externas, porém posso utilizar se necessário.
